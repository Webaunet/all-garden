# ALL GARDEN — maquette de site

Maquette du site vitrine d'ALL GARDEN, paysagiste à Marcoussis (91). Site statique, ce n'est pas le site définitif.

Pages : `index.html` (accueil), `prestations.html`, `realisations.html`, `contact.html`, `mentions-legales.html`.

Les pages sont générées par `outils/build.py` ; les images sont optimisées par `outils/optimiser_images.py`.
